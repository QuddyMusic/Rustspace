# backspace-rs

Кроссплатформенный клиент для [Backspace](https://github.com/TheZwiss/backspace), полностью на Rust.

## Статус

Этапы 0–3 закрыты: воркспейс собирается целиком, 319 тестов зелёные, `clippy --workspace --all-targets -- -D warnings` чист.

Что умеют GUI и TUI:

- вход, чат: отправка, правка, удаление сообщений, реакции, подтверждение прочтения;
- друзья, заявки, поиск пользователей, личные каналы;
- **мультиинстансность**: несколько подключённых инстансов одновременно, объединённый сайдбар пространств и личных каналов с метками origin, переключение активного инстанса, добавление и отключение удалённых инстансов;
- федеративные хелперы: `peerHomeWithRemote`, `ensureRemoteCredential`, `maybeAutoReattach` — токены per-remote и автоматическое переподключение.

`bs-voice` — осознанная заглушка до Этапа 4.

## Сборка

```sh
cargo build              # всё
cargo test --workspace   # тесты
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all
```

Алиасы: `cargo fc` (fmt --check), `cargo c` (clippy), `cargo t` (тесты), `cargo f` (fmt).
Полный прогон CI — последовательно, одной строкой:

```sh
cargo fc && cargo c && cargo t
```

## Правила

- `unsafe_code = "deny"` на уровне воркспейса. Любой `unsafe` — через явное исключение с обоснованием.
- `.unwrap()`, `.expect()`, `panic!()`, `todo!()` запрещены в продакшн-коде (clippy deny).
- Ошибки: `thiserror` в библиотеках, `anyhow` в приложении.
- Права — `bitflags` над `u64`, сериализация decimal string (JSON теряет биты выше 2^53).
- Snowflake ID — строки, не числа.
- `Origin` — enum `{Home, Remote(Url)}`, не `String` с `''`.
