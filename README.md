# backspace-rs

Кроссплатформенный клиент для [Backspace](https://github.com/TheZwiss/backspace), полностью на Rust.

## Статус

Воркспейс собирается целиком, тесты зелёные, `clippy --workspace --all-targets -- -D warnings` чист.

Что умеют GUI и TUI:

- вход, чат: отправка, правка, удаление сообщений, реакции, подтверждение прочтения;
- друзья, заявки, поиск пользователей, личные каналы;
- **один инстанс за раз**: параллельный вход в несколько инстансов запрещён структурно; чтобы сменить инстанс, нужно выйти из текущего;
- личные сообщения и история (подгрузка старых сообщений) в GUI;
- безопасный транспорт по умолчанию: только `https`/`wss`, открытый `http` вне loopback — по явному согласию (`--allow-insecure` в TUI, флажок в форме GUI);
- библиотечные федеративные хелперы (`peerHomeWithRemote`, `ensureRemoteCredential`, `maybeAutoReattach`) остаются в `bs-core` для будущего сервера, приложениями не используются.

Подробности — в [AUDIT.md](AUDIT.md).

`bs-voice` — осознанная заглушка до Этапа 4.

## Структура воркспейса

| Крейт | Назначение | Статус |
|---|---|---|
| `bs-types` | Типы данных протокола (User, Space, Channel, Message, события) | ✅ 50 тестов |
| `bs-permissions` | Битовые права, иерархия ролей, override-логика | ✅ 13 тестов |
| `bs-api` | REST-клиент (`/api/*`), Bearer JWT, ошибки с кодами | ✅ 45 тестов |
| `bs-ws` | WebSocket-клиент, heartbeat, реконнект, парсинг событий | ✅ 10 тестов |
| `bs-instances` | Соединение с инстансом (диспетчер, реконнект); реестр и мультиплексор — библиотечно | ✅ 14 тестов |
| `bs-identity` | Логин/регистрация, хранение токенов, per-remote credentials, `UserKey`/`myRowIds` | ✅ 31 тест |
| `bs-voice` | Голос/видео (LiveKit) — отдельный трек | 🚧 заглушка, Этап 4 |
| `bs-core` | Склейка: состояние, стор, команды, `MultiCache` с origin-метками, федеративные хелперы | ✅ 57 тестов |
| `bs-app` | GUI (`egui`/`eframe`) + точка входа | ✅ 62 теста, чат, ЛС, история, соцэкран, один инстанс |
| `bs-tui` | Терминальный клиент (`ratatui`/`crossterm`) для ручной проверки протокола | ✅ 37 тестов, чат, ЛС, история, соцэкран, один инстанс |

## Сборка

```sh
cargo build              # всё
cargo test --workspace   # тесты
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all
```

Алиасы: `cargo fc` (fmt --check), `cargo c` (clippy), `cargo t` (тесты), `cargo f` (fmt).
Полный прогон CI — последовательно, одной строкой:

```sh
cargo fc && cargo c && cargo t
```

## Правила

- `unsafe_code = "deny"` на уровне воркспейса. Любой `unsafe` — через явное исключение с обоснованием.
- `.unwrap()`, `.expect()`, `panic!()`, `todo!()` запрещены в продакшн-коде (clippy deny).
- Ошибки: `thiserror` в библиотеках, `anyhow` в приложении.
- Права — `bitflags` над `u64`, сериализация decimal string (JSON теряет биты выше 2^53).
- Snowflake ID — строки, не числа.
- `Origin` — enum `{Home, Remote(Url)}`, не `String` с `''`.
