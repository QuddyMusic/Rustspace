# backspace-rs

Кроссплатформенный клиент для [Backspace](https://github.com/TheZwiss/backspace), полностью на Rust.
Основной клиент — графический (`egui`/`eframe`, крейт `bs-app`, бинарник `backspace-rs`);
рядом лежит терминальный клиент `bs-tui` для проверки протокола.

## Статус

Воркспейс собирается целиком, тесты зелёные, `clippy --workspace --all-targets -- -D warnings` чист.
Цель — полный паритет с веб-клиентом оригинала; список того, чего ещё нет, — в
[ROADMAP.md](ROADMAP.md).

Что умеет GUI:

- **Вход.** Логин и регистрация, открытый `http` вне loopback — только по явному согласию.
  Вход сохраняется: после перезапуска клиент входит по токену без пароля
  (файл `session.json`, права `0600`; выход из аккаунта его стирает).
- **Пространства.** Каналы и категории, роли и права, переопределения прав каналов, участники,
  баны, приглашения, заявки на вступление, каталог, настройки уведомлений
  (на пространство и на канал, отключение на время).
- **Сообщения.** Отправка, правка, удаление, ответы, реакции, упоминания, разметка,
  подтверждение прочтения, подгрузка истории, поиск по сообщениям с фильтрами и переходом к
  найденному.
- **Файлы и картинки.** Загрузка с прогрессом, просмотр картинок, скачивание вложений на диск
  (одного или всех файлов сообщения), аватарки, стикеры, GIF.
- **Личные сообщения.** Личные и групповые каналы, друзья, заявки, профили пользователей.
- **Несколько инстансов.** Федеративные инстансы подключаются через домашний; в рейле — иконки
  всех подключённых, у каждого свой кэш и свои уведомления.
- **Аккаунт и администрирование.** Профиль, смена пароля, удаление аккаунта, панель администратора
  инстанса.
- **Голос** (сборка с `--features voice`). Подключение к голосовым каналам и звонки в личных
  сообщениях через LiveKit, микрофон и наушники (mute/deafen), выбор устройств, громкость
  участников, индикатор речи, эхо-/шумоподавление. Звуки интерфейса: вход и выход из канала
  (свой и чужие), mute/unmute, deafen/undeafen, вызов в личных звонках (входящий и исходящий,
  «не беспокоить» глушит входящий); без звукового устройства приложение молчит.
  Файлы звуков — из оригинала (`crates/bs-app/assets/sounds`, лицензия та же, AGPL-3.0-only).

Что в голосе пока **не** сделано: камера и демонстрация экрана в интерфейсе (транспорт для них
в `bs-voice` есть), звук новых сообщений, проверка микрофона. Подробности — в
[ROADMAP.md](ROADMAP.md).

Безопасность и известные ограничения — в [AUDIT.md](AUDIT.md).

## Структура воркспейса

| Крейт | Назначение | Тесты |
|---|---|---|
| `bs-types` | Типы данных протокола (User, Space, Channel, Message, события) | 55 |
| `bs-permissions` | Битовые права, иерархия ролей, override-логика | 13 |
| `bs-api` | REST-клиент (`/api/*`), Bearer JWT, загрузка и скачивание файлов, ошибки с кодами | 102 |
| `bs-ws` | WebSocket-клиент, heartbeat, реконнект, парсинг событий | 10 |
| `bs-instances` | Соединение с инстансом (диспетчер, реконнект), вход по паролю и по токену | 13 |
| `bs-identity` | Логин/регистрация, хранение токенов, per-remote credentials, `UserKey`/`myRowIds` | 29 |
| `bs-media` | Декодирование картинок и GIF с лимитами размера и пикселей | 12 |
| `bs-voice` | Голос и видео поверх LiveKit: сессия, устройства, громкость, миксер, VAD, экран/камера (транспорт) | ≈60¹ |
| `bs-core` | Состояние и кэш инстанса, применение событий, уведомления, федеративные хелперы | 65 |
| `bs-app` | GUI (`egui`/`eframe`) и точка входа | 169 |
| `bs-tui` | Терминальный клиент (`ratatui`/`crossterm`), один инстанс | ≈35¹ |

¹ Для `bs-voice` и `bs-tui` нужна `libwebrtc`, которая скачивается при сборке; в изолированной
среде разработки они не запускались, число — по количеству тестовых функций.

## Сборка и запуск

Нужен Rust (версия закреплена в `rust-toolchain.toml`, `rustup` подтянет её сам).

### Графический клиент

```sh
# собрать и сразу запустить (отладочная сборка, без голоса)
cargo run -p bs-app

# то же, с голосом через LiveKit
cargo run -p bs-app --features voice

# оптимизированная сборка
cargo build --release -p bs-app
./target/release/backspace-rs                              # без голоса
cargo build --release -p bs-app --features voice           # с голосом (тот же бинарник)
```

При запуске откроется форма входа: адрес инстанса, имя пользователя и пароль.
Для инстанса по `http://` вне loopback поставьте флажок «Разрешить незащищённое соединение (http)».
Если вы входили раньше, клиент сам войдёт по сохранённому токену.

Подробный лог: `RUST_LOG=bs_app=debug,bs_voice=debug cargo run -p bs-app --features voice`
(по умолчанию уровень `info`).

Где хранится сессия: `~/.config/backspace-rs/session.json` (Linux, учитывается `XDG_CONFIG_HOME`),
`~/Library/Application Support/backspace-rs/` (macOS), `%APPDATA%\backspace-rs\` (Windows).
Чтобы выйти насовсем, нажмите «Выйти» в настройках или удалите этот файл.

Системные зависимости:

- для сборки без голоса отдельных пакетов обычно не нужно;
- для звуков интерфейса (`--features sounds`, входит в `voice`) на Linux нужна `libasound2-dev`
  (Fedora: `alsa-lib-devel`);
- для голоса (`--features voice`) при сборке скачивается `libwebrtc`, нужны `clang`/`libclang`,
  `pkg-config`; на Linux — ещё заголовки PipeWire (захват звука и экрана) и средства разработки X11/Wayland;
- диалоги выбора файла на Linux используют `xdg-desktop-portal` или `zenity`.

### Терминальный клиент

```sh
cargo run -p bs-tui                      # обычный запуск
cargo run -p bs-tui -- --allow-insecure  # разрешить http вне loopback
```

### Проверки

```sh
cargo test --workspace                   # тесты
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all
```

Алиасы: `cargo fc` (fmt --check), `cargo c` (clippy), `cargo t` (тесты), `cargo f` (fmt).
Полный прогон CI — последовательно, одной строкой:

```sh
cargo fc && cargo c && cargo t
```

## Правила

- `unsafe_code = "deny"` на уровне воркспейса (в `bs-voice` — `forbid`). Любой `unsafe` — через явное исключение с обоснованием.
- `.unwrap()`, `.expect()`, `panic!()`, `todo!()` запрещены в продакшн-коде (clippy deny).
- Ошибки: `thiserror` в библиотеках, `anyhow` в приложении.
- Права — `bitflags` над `u64`, сериализация decimal string (JSON теряет биты выше 2^53).
- Snowflake ID — строки, не числа.
- `Origin` — enum `{Home, Remote(Url)}`, не `String` с `''`.
