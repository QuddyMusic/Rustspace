Сервер на Rust

Здесь нет веб-версии

Этот инстанс работает на bs-server и принимает пользователей только из десктоп-клиента Rustspace, написанного на Rust. Из браузера войти не получится.

Как подключиться

  1. Установите клиент Rustspace для Linux, Windows или macOS: {{CLIENT_LINK_RU}}.
  2. Укажите адрес инстанса на экране входа: {{ORIGIN}} Щелчок выделяет адрес целиком — его можно сразу скопировать.
  3. Войдите или зарегистрируйтесь. Голос, видео, стримы и сквозное шифрование личных переписок работают в клиенте.

Rust server

There is no web app here

This instance runs bs-server and only accepts the Rustspace desktop client, written in Rust. You cannot sign in from a browser.

How to connect

  1. Install the Rustspace client for Linux, Windows or macOS: {{CLIENT_LINK_EN}}.
  2. Enter the instance address on the sign-in screen: {{ORIGIN}} One click selects the whole address, ready to copy.
  3. Sign in or create an account. Voice, video, screen sharing and end-to-end encrypted direct messages work in the client.
