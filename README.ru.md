# backspace-rs

*[English](README.md) · Русский*

Кроссплатформенный клиент для [Backspace](https://github.com/TheZwiss/backspace), полностью на
Rust. Основной клиент — графический (`egui`/`eframe`, крейт `bs-app`, бинарник
`backspace-rs`); рядом лежит терминальный клиент `bs-tui` для проверки протокола.

Цель — полная совместимость с оригиналом: клиент работает с неизменёнными инстансами Backspace
(в том числе федеративными) и умеет всё, что умеют веб- и десктоп-клиенты оригинала. Чего ещё
нет — в [дорожной карте](ROADMAP.ru.md).

## Статус

Воркспейс собирается целиком; `cargo clippy --workspace --all-targets --all-features -D warnings`
чист, все тесты зелёные. Совместимость проверяется на настоящем сервере: контрактный стенд
(`cargo xtask contract`) поднимает оригинальный Node-сервер и строго разбирает каждый кадр
WebSocket и каждый REST-ответ, который получает клиент.

### Что умеет GUI

- **Вход.** Логин и регистрация (с приглашением и проверкой имени на лету). Открытый `http`
  вне loopback — только по явному согласию. Сессия переживает перезапуск: токен в системном
  хранилище ключей (Secret Service, Keychain, Credential Manager), запасной путь — файл `0600`.
- **Пространства.** Каналы и категории, роли и права, переопределения прав каналов, участники,
  баны, приглашения, заявки на вступление, каталог инстанса, настройки уведомлений пространства
  и канала (в том числе отключение на время).
- **Сообщения.** Отправка, правка, удаление, ответы, реакции, упоминания, разметка,
  прочитанность, подгрузка истории, поиск с фильтрами и переходом к найденному. Блоки кода
  подсвечиваются по языку из ограды (` ```bash `, ` ```rust `…; понимаются и псевдонимы Prism). Текст длиннее
  предела сервера (4000 символов) уходит несколькими сообщениями подряд; блок кода на разрыве
  закрывается ` ``` ` и открывается той же оградой (с языком) в следующем сообщении.
- **Файлы и медиа.** Загрузка с прогрессом, просмотр картинок, скачивание вложений (одного или
  всех), аватарки, баннеры, стикеры, GIF (поиск Klipy, избранное).
- **Личные сообщения.** Беседы один на один и групповые, друзья и заявки, профили,
  приглашения в пространство карточкой в ЛС.
- **Федерация.** Несколько инстансов сразу, чужие — входом через домашний аккаунт. Приглашение
  или запись каталога с ещё не подключённого инстанса подключают его сразу и вступают в
  пространство. В «Обзоре» — общий каталог других инстансов (`/api/directory`), если он
  настроен на домашнем инстансе.
- **Голос и видео** (`--features voice`). Голосовые каналы и звонки в ЛС через LiveKit;
  микрофон и звук; громкость микрофона и вывода 0–200 %, громкость каждого участника и
  «заглушить у себя», громкость трансляции и её приглушение, пока кто-то говорит;
  эхо-/шумоподавление и АРУ; проверка микрофона; подсветка говорящих. Камера
  (`--features camera`) и демонстрация экрана со сценой звонка над чатом: захват libwebrtc
  (под Wayland — через портал ScreenCast), 540p–4K или «как есть», 30–120 к/с, VP9 или
  H.264, плавность или чёткость — всё в пределах лимитов трансляций инстанса; системный звук
  без звука самого Backspace (запись по приложениям через PulseAudio/PipeWire на Linux,
  loopback вывода на Windows и macOS). Чужие трансляции и их звук принимаются, только пока
  вы их смотрите, а ведущий видит, кто смотрит.
- **Рабочий стол** (`--features desktop`). Значок в трее: показать/скрыть, микрофон, звук,
  выход; закрытие окна прячет его в трей. Глобальные горячие клавиши (в том числе рация с
  отпусканием) на X11, Windows и macOS, а под Wayland — через портал XDG GlobalShortcuts
  (сочетания назначаются в настройках системы); в окне сочетания работают всегда.
- **Оформление.** Шесть встроенных тем, свой акцент, правка любого цвета, скругление (всё
  окно собрано из скруглённых модулей, которые ему следуют), компактная лента, импорт и экспорт темы в JSON, масштаб. Звуки интерфейса из оригинала.
  Системные уведомления по правилам оригинала (уровни, отключения, «не беспокоить»,
  упоминания).
- **Языки.** Русский и английский встроены и переключаются на лету; любой другой язык
  добавляется каталогом JSON в `<папка настроек>/locales/<код>.json` (см. «Настройки → Язык»).
- **Страница «Backspace»** в боковой панели, как проектный хаб оригинала: что нового в
  домашнем инстансе (с точкой «обновлено»), ссылки проекта, сообщение об ошибке, версия и
  исходный код этого сервера.
- **Обновления клиента.** «Настройки → О клиенте» проверяет релизы собственного репозитория
  клиента на GitHub (`owner/repo`; значение по умолчанию можно вшить при сборке:
  `BS_UPDATE_REPO=owner/repo`) и предлагает файл под вашу систему.
- **Администрирование.** Профиль, смена пароля, удаление аккаунта; панель администратора
  инстанса (настройки, пользователи, хранилище, регистрация, федерация, лимиты трансляций,
  телеметрия, обновления).

Безопасность и известные ограничения — в [AUDIT.md](AUDIT.md).

## Сборка и запуск

Версия Rust закреплена в `rust-toolchain.toml`, `rustup` подтянет её сам. Возможности (голос,
камера, трей…) выбираются **при сборке**; у самой программы переключателей возможностей нет.

### Сборка

```sh
cargo build --release -p bs-app                                     # GUI без голоса
cargo build --release -p bs-app --features voice,camera,desktop     # всё сразу
cargo build --release -p bs-tui                                     # терминальный клиент
```

В пакете `bs-app` один бинарник — **`backspace-rs`**, в `bs-tui` — **`bs-tui`**. Release-сборка
лежит в `target/release/` (отладочная, без `--release`, — в `target/debug/`).

### Запуск собранного

```sh
./target/release/backspace-rs            # Linux и macOS
.\target\release\backspace-rs.exe        # Windows
./target/release/bs-tui                  # терминальный клиент
./target/release/bs-tui --allow-insecure # bs-tui: разрешить http вне loopback
```

Бинарник самодостаточен: его можно скопировать куда угодно и запустить. Параметров командной
строки у `backspace-rs` нет, всё настраивается в приложении («Настройки»). Из окружения
читается только `RUST_LOG` для логов, например
`RUST_LOG=bs_app=debug,bs_voice=debug ./target/release/backspace-rs`. Форма входа спрашивает
адрес инстанса, имя и пароль; для инстанса по `http://` вне loopback поставьте флажок
«Разрешить незащищённое соединение (http)».

Чтобы программа была в `PATH`:

```sh
cargo install --path crates/bs-app --features voice,camera,desktop   # → ~/.cargo/bin/backspace-rs
backspace-rs
```

### Собрать и сразу запустить (для разработки)

`cargo run` собирает пакет и запускает его бинарник (`backspace-rs` у `bs-app`) с теми же
флагами, что вы передали:

```sh
cargo run -p bs-app                                    # отладочная сборка без голоса
cargo run --release -p bs-app --features voice         # оптимизированная, с голосом
cargo run -p bs-tui -- --allow-insecure                # аргументы после `--` идут программе
```

### Флаги сборки `bs-app`

| Флаг | Что добавляет | Что нужно для сборки |
|---|---|---|
| `sounds` | звуки интерфейса (rodio) | Linux: `libasound2-dev` |
| `voice` | голос, демонстрация экрана, сцена звонка (включает `sounds`) | clang **21+**, `libclang`, `pkg-config`; Linux: PipeWire, заголовки X11/Wayland; `libwebrtc` скачивается при сборке |
| `camera` | веб-камера через nokhwa (V4L2, Media Foundation, AVFoundation; включает `voice`) | — |
| `tray` | значок в трее и сворачивание в него | Linux: `libgtk-3-dev`, `libayatana-appindicator3-dev` |
| `global-hotkeys` | горячие клавиши вне окна (X11, Windows, macOS; Wayland — через портал GlobalShortcuts) | Linux: заголовки X11 |
| `desktop` | `tray` + `global-hotkeys` | см. выше |

Ещё: для хранилища ключей при сборке нужна `libdbus-1-dev`, при работе — демон Secret Service
(без него токен пишется в файл `0600`); диалоги выбора файлов на Linux используют
`xdg-desktop-portal` или `zenity`; демонстрации экрана под Wayland нужен `xdg-desktop-portal` с
поддержкой ScreenCast (GNOME, KDE или wlr) и PipeWire, системному звуку на Linux — PulseAudio
или `pipewire-pulse`. Звук идёт через ALSA по умолчанию, а оттуда — в PulseAudio
или PipeWire через их ALSA-плагины. `cargo run -p bs-voice --example audio_check` покажет
звуковые устройства и уровень микрофона.

### Где лежат данные

`~/.config/backspace-rs/` на Linux (учитывается `XDG_CONFIG_HOME`),
`~/Library/Application Support/backspace-rs/` на macOS, `%APPDATA%\backspace-rs\` на Windows:
`session.json` (адрес инстанса; токен — в хранилище ключей), `prefs.json` (тема, масштаб,
голос, звуки, уведомления, горячие клавиши, язык), `locales/` (свои переводы).

### Упаковка

```sh
cargo install cargo-packager --locked
cargo packager --release -p bs-app --formats deb,appimage   # Linux
cargo packager --release -p bs-app --formats dmg            # macOS
cargo packager --release -p bs-app --formats nsis           # Windows
```

Пакеты — в `target/packages`; иконка и `.desktop` — в `packaging/linux`.

### Проверки

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace --all-features
cargo xtask contract --server ../backspace          # поднять оригинал и проверить клиент
cargo xtask contract --url http://127.0.0.1:3000    # против запущенного сервера
```

Контрактному стенду нужны Node.js 22+ и `pnpm install` в checkout Backspace. Алиасы:
`cargo fc` (проверка fmt), `cargo c` (clippy), `cargo t` (тесты), `cargo f` (fmt).

## Сервер (`bs-server`)

Сервер на Rust повторяет оригинальный сервер Backspace: те же маршруты, события WebSocket,
переменные окружения и та же база SQLite. Файл базы оригинала открывается как есть (миграции
те же, уже применённые не повторяются), и обратно — базу, с которой работал `bs-server`,
открывает оригинал. Токены и хеши паролей общие.

**Что перенесено:** регистрация и вход, приглашения; профиль, пароль, удаление аккаунта;
пространства, участники, роли, баны, каналы, категории, переопределения прав; сообщения,
реакции, позиции чтения, «тычки»; личные и групповые переписки; друзья и поиск людей;
настройки уведомлений; голосовые каналы, звонки, модерация голоса, токены LiveKit; настройки
инстанса. Каждый маршрут и каждое событие сверяются с оригиналом сценариями из
`tools/compat`.

**Чего пока нет:** загрузка файлов (tus) и раздача `/api/uploads`, предпросмотр ссылок,
поиск по сообщениям, каталог пространств и заявки на вступление, стикеры, GIF, хранилище и
пользователи в админке, раздача веб-клиента, федерация (доставка и приём событий между
инстансами). Дальше по плану — PostgreSQL, двухфакторная аутентификация и сквозное
шифрование ЛС; см. [ROADMAP.ru.md](ROADMAP.ru.md). Для инстанса с пирами федерации сервер
пока не годится: он об этом предупреждает при запуске.

### Сборка

```sh
cargo build --release -p bs-server      # target/release/backspace-server
```

Нужен только компилятор C (SQLite собирается вместе с сервером). Node.js не нужен.

### Запуск

```sh
JWT_SECRET="$(openssl rand -hex 32)" \
DB_PATH=data/backspace.db UPLOAD_DIR=data/uploads \
target/release/backspace-server
```

Сервер слушает `0.0.0.0:3000`. Первый зарегистрированный пользователь становится
администратором. Останавливается по `Ctrl+C` или `SIGTERM`, дожидаясь открытых запросов.

Перейти с оригинального сервера: остановите его, сделайте копию базы и запустите
`backspace-server` с теми же `JWT_SECRET`, `DB_PATH` и `UPLOAD_DIR`. Вернуться — так же в
обратную сторону.

### Настройка

Переменные окружения те же, что у оригинала.

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `JWT_SECRET` | — (обязательна) | Ключ подписи токенов, не короче 32 знаков |
| `JWT_EXPIRES_IN` | `30d` | Срок жизни токена (`30d`, `12h`, `3600`) |
| `PORT`, `HOST` | `3000`, `0.0.0.0` | Где слушать |
| `DB_PATH` | `data/backspace.db` | Файл базы SQLite |
| `UPLOAD_DIR` | `data/uploads` | Каталог загруженных файлов |
| `MAX_UPLOAD_SIZE` | `104857600` | Предел размера файла, байт |
| `DOMAIN` | — | Домен инстанса (ссылки приглашений, имена `user@domain`) |
| `PUBLIC_ORIGIN` | — | Полный внешний адрес, если он не `https://DOMAIN` |
| `TRUSTED_PROXY_HOPS` | `1` | Сколько прокси перед сервером пишут `X-Forwarded-For` (0–4). От этого зависят ограничения частоты: за одним nginx — `1`, без прокси — `0` |
| `REGISTRATION_OPEN` | `true` | Открыта ли регистрация без приглашения (администратор меняет в настройках) |
| `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` | — | Сервер LiveKit для голоса; без них голос отключён |
| `DIRECTORY_ENDPOINT` | каталог проекта | Адрес каталога пространств; пустая строка отключает |
| `DISABLE_RATE_LIMITS` | `false` | Отключить ограничения частоты (только для тестов) |
| `BACKSPACE_SOURCE_URL`, `BACKSPACE_COMMIT` | — | Что показывать в сведениях об инстансе |
| `BS_PASSWORD_HASH_COST` | `12` | Стоимость bcrypt (4–16); менять только для тестов |
| `RUST_LOG` | `info` | Подробность журнала (`debug`, `bs_server=trace`) |

Перед сервером нужен обратный прокси с TLS, который пропускает WebSocket на `/ws`.

### Проверка совместимости

`tools/compat` поднимает оригинальный сервер и `bs-server` на копии одной базы и выполняет
на обоих одинаковые сценарии, сравнивая ответы и события WebSocket:

```sh
tools/compat/up.sh                    # нужен checkout Backspace с `pnpm install`
python3 tools/compat/s_spaces.py      # и s_channels, s_messages, s_dm, s_social,
                                      # s_account, s_voice, s_admin; cmp_ready.py
```

Путь к checkout задаётся переменной `ORIG` (см. начало `up.sh`).

## Переводы

Ключи строк — русский исходный текст (как в gettext). Английский каталог —
`crates/bs-app/locales/en.json`; тест падает, если у строки в коде нет английского перевода,
а подстановки (`{name}`) обязаны совпадать. Чтобы добавить язык, скопируйте `en.json`,
впишите в `"@language"` название языка на нём самом, переведите значения и положите файл в
`<папка настроек>/locales/<код>.json` — язык сразу появится в «Настройки → Язык».

## Правила

- `unsafe_code = "deny"` во всём воркспейсе (в `bs-voice` — `forbid`).
- `.unwrap()`, `.expect()`, `panic!()`, `todo!()` запрещены в рабочем коде (clippy deny).
- Ошибки: `thiserror` в библиотеках, `anyhow` в приложении.
- Права — `bitflags` над `u64`, сериализуются строкой (JSON теряет биты выше 2^53).
  Snowflake-идентификаторы — строки. `Origin` — enum `{Home, Remote(Url)}`.
